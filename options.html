Window automation

Choose where Tab Bundlr runs

Use all Chrome windows, or choose any combination of the windows open right now. Leave every window unchecked to disable grouping everywhere.

Tab Bundlr remembers Selected windows. If Chrome restarts with one window, that window is restored as the selected destination. With several restored windows, select the destination again so Tab Bundlr does not guess.

Workspace settings

Workspace settings

Enable only the workspace categories you want Tab Bundlr to manage, then arrange and color them here. Turning off a source category lets matching tabs fall through to another enabled URL rule. Existing open tabs are re-evaluated when a category changes.

Optionally keep chrome:// pages such as Extensions and Settings in one standard Smart Group. This does not create a broad URL rule.

Smart groups

Personal tab rules

Create an explicit URL rule for a named group. For example, use Documentation and https://docs.example.com/product/. Matching deeper pages will join that Smart Group. Use Move up and Move down here to set the individual Smart Group order.

Saved destinations

Saved workspace rules

Save a URL prefix to a workspace from the popup, or add and edit rules here. A more specific saved workspace rule can override a broader Smart Group prefix.

A short unique ID stored with this workspace in your settings and backups.

Rule tester

Test a URL

See every matching Smart Group and saved workspace rule in priority order. The longest prefix wins, and Smart Groups win exact-length ties.

Optional connections

Connections from JSON

A connection can match supported pages and read workspace names from an HTTPS service. Its JSON, requested addresses, and credentials remain visible here. New connections stay off until you review and enable them. Learn how connections handle data.

Backup

Export or import settings

Export grouping rules, connection definitions, colors, ordering, and review preferences. Credentials, open tabs, paused windows, Chrome group IDs, Focus holds, and undo history are excluded. Imported connections remain off and require their credentials again.
