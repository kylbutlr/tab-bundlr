# Security

Tab Bundlr reads browser tab URLs and titles and may store credentials for optional connections. Do not put credentials, private URLs, settings exports, or confidential browser data in public reports.

For a suspected vulnerability, use [GitHub private vulnerability reporting](https://github.com/kylbutlr/tab-bundlr/security/advisories/new) if it is enabled. If that form is unavailable, open a minimal issue requesting a private contact without including exploit details or sensitive data.

Use the current release candidate when reporting. Include the version, the affected feature, and a safe description of the impact. This project does not promise a fixed response time.
