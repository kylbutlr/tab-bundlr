First use

Start with one rule

  1. Create a Smart Group. In Settings, give it a name and an HTTP or HTTPS URL prefix.
  2. Open matching pages. A prefix matches itself and deeper paths. The most specific matching prefix wins.
  3. Use Fix. Tab Bundlr applies your rules while protecting pinned tabs and groups you created manually in Chrome.
  4. Review the result. Undo the latest Tab Bundlr move if needed. Turn on Automatic Tab Bundling only when you want rules applied as tabs open or navigate.

Actions

What the controls do

Fix
Applies known URL rules to recognized tabs in the current window. It does not move pinned tabs or tabs in manual Chrome groups.
Organize
Reorders Tab Bundlr-managed groups. It does not close tabs or change manual groups.
Focus
Expands one workspace, collapses other managed groups, and activates a tab in the chosen workspace.
Move here
Moves the active tab once. It does not save a URL rule.
Save URL rule
Saves a URL prefix so matching pages can return to the same workspace.
Keep as home base
Remembers one exact web address and restores an inactive copy when its last copy disappears or navigates away.
Pause this window
Stops Tab Bundlr from sorting that window for the current Chrome session.
Review tabs
Shows unassigned, duplicate, and probably stale tabs. Closing tabs always requires a separate selection and confirmation.

Privacy

Local by default

Tab Bundlr has no hosted account, backend, telemetry, advertising, analytics, or cloud synchronization. It does not inject scripts into pages or read page bodies, form contents, cookies, or passwords.

What it reads

Open-tab titles, URLs, activity time, pinned state, window placement, and Chrome group membership. This is used to match rules, show review information, organize tabs, and protect active or pinned tabs.

What it stores

Rules, preferences, optional connection definitions and credentials, home-base URLs, managed-group records, and recent move history in Chrome extension storage. Paused windows, temporary focus holds, and tab activation history are session state.

What leaves the device

Nothing leaves the device unless you enable an optional connection. A connection may send a read-only HTTPS request to its listed service addresses, including configured credential headers and values matched from a supported page URL.

How to delete it

Remove individual rules and connections in Settings. Removing a connection also removes its saved credentials. Remove Tab Bundlr through chrome://extensions to delete its extension storage.

The public policy is also available in the Tab Bundlr source repository.

Optional connections

You approve every service address

Connections are visible JSON configurations. They can recognize supported page URLs, make HTTPS GET requests to listed addresses, and use selected response fields to choose a workspace. They cannot send request bodies, make write requests, run scripts, or follow redirects.

Newly imported connections stay off. Before first access, Tab Bundlr shows the requested addresses and Chrome asks you to approve them. Credentials are stored separately from the JSON, excluded from settings exports, and sent only as the headers declared by that connection.

Support

Report an issue safely

Include your Chrome and Tab Bundlr versions, the action you tried, and what happened. Do not include API tokens, authorization headers, private URLs, exported browser data, or confidential workspace information.
