# Support

For bugs or feature requests, open an issue in the [Tab Bundlr issue tracker](https://github.com/kylbutlr/tab-bundlr/issues) with:

- Chrome version and operating system
- Tab Bundlr version from `chrome://extensions`
- The action being attempted
- Expected and observed behavior
- Whether Automatic Tab Bundling and the current window were enabled
- A redacted source definition when a Workspace Source is involved

Never include API tokens, authorization headers, private URLs, exported browser data, or confidential workspace information in an issue.

Before filing, follow [Troubleshooting](troubleshooting.md) and run the relevant checks in [Verification](verification.md).

The installed extension also provides a **Help** page with first-use steps, action definitions, privacy details, and safe issue-reporting guidance.

The [Tab Bundlr issue tracker](https://github.com/kylbutlr/tab-bundlr/issues) is the public support destination. Configure it as the support URL before Chrome Web Store submission.
