# Tab Bundlr v1.1.0

- Adopt pinned App Stylr v1.4.1 with charcoal surfaces, Sage accents, Geist type and precise control geometry.
- Use quieter feedback surfaces while preserving meaningful Chrome workspace colors and compact popup controls.
- Preserve the product glyph over the neutral Graphite tile. Supply a directly rendered 512px PNG and select 128px artwork for high-density extension-management cards.
- Refresh the actual-interface still and animation using fictional data, with capture provenance.

Product workflows and requested permissions are unchanged.

## Verification

124 source tests and the generated-source check passed. ZIP integrity and runtime allowlists were verified. Rendered review covered the affected pages, narrow layouts and sampled interaction states. Installed Chromium 151 at 2× density selected the corrected 128px management icon. The exact package also passed all 14 existing installed-Chromium smoke checks, including grouping, undo, pinned/manual-group protections, rule editing, duplicate-close confirmation and missing host access.

## Coverage limits

The complete native stable Chrome/Edge functional matrix was not repeated for this visual release. Native permission dialogs, long-term persistence, service-worker lifecycle, and a screen-reader walkthrough remain unverified for this version. Source tests and fictional-data captures do not establish those outcomes.

Downloads are installed unpacked and updated manually. Keep the same installation folder when updating.
