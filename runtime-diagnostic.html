Routing and speed diagnostic

Records routing decisions, temporary tab/window IDs, counts and popup timings. No URLs, titles, page content or network requests. Nothing is sent anywhere.

Capture lasts five minutes, holds at most 128 entries, and is cleared if Chrome restarts the extension worker. A fresh worker starts a short capture automatically. There is no polling or background storage writing.

  1. Start a capture here, then return to your Meet window.
  2. Drag a tab into it and open one external link, as before. Open the Tab Bundlr popup once.
  3. Return here, refresh the report, then download it. Review the file before sharing it.
